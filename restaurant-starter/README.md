# 🏔️ Sagarmatha Restaurant Website

A modern, responsive restaurant website built with **React** and **Firebase** for **Sagarmatha**, an authentic Nepali restaurant that brings the rich flavors, culture, and hospitality of the Himalayas to Durham, North Carolina.

---

## 🚀 Tech Stack

- **Frontend:** React 18 + Vite
- **Routing:** React Router DOM
- **Database:** Firebase Firestore
- **Styling:** Custom CSS3
- **Version Control:** Git & GitHub

---

## ✨ Features

- 🍛 Authentic Nepali restaurant website with a unique Himalayan-inspired design
- 📖 Five fully responsive pages: Home, About, Menu, Location, and Contact
- 🔥 Dynamic menu loaded from Firebase Firestore
- 📱 Responsive layout for desktop, tablet, and mobile devices
- 📩 Interactive contact form with client-side validation
- 🗺️ Embedded Google Maps location
- ⚡ Fast client-side routing using React Router
- 🎨 Custom branding, logo, and Nepali-inspired color palette

## 🛠️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/aryalankit121/sagarmatha-restaurant.git
```

### 2. Navigate to the Project

```bash
cd sagarmatha-restaurant
cd restaurant-starter
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open the Application

Visit:

```
http://localhost:5173
```
